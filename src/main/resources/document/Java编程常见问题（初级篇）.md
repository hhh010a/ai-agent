# Java编程常见问题（初级篇）

#### Q1: String、StringBuilder和StringBuffer有什么区别？

- **String** 是不可变对象，每次修改都会创建新的字符串对象，适合少量字符串操作或线程安全场景。
- **StringBuilder** 是可变的，线程不安全，但性能高，适合单线程下大量字符串拼接。
- **StringBuffer** 也是可变的，但所有方法都加了`synchronized`，线程安全，适合多线程环境，性能略低于`StringBuilder`。

#### Q2: equals()方法和==运算符有什么区别？

- **==** 比较的是两个对象的**内存地址**，即是否指向同一个对象。
- **equals()** 是Object类的方法，默认实现与`==`相同，但许多类（如String、Integer）重写了该方法，使其比较对象的内容。
- 使用时应根据实际需求选择，比较内容时优先重写`equals()`。

#### Q3: final关键字在Java中有什么作用？

- 修饰**变量**：变为常量，基本类型值不可变，引用类型地址不可变。
- 修饰**方法**：方法不可被重写。
- 修饰**类**：类不可被继承。
- 修饰**参数**：参数在方法内不可被修改。

#### Q4: Java中如何处理异常？try-catch-finally的执行顺序是怎样的？

- 异常处理使用`try`、`catch`、`finally`块。`try`中放可能出错的代码，`catch`捕获并处理异常，`finally`无论是否异常都会执行（用于释放资源）。
- 执行顺序：
  1. 执行`try`块，若发生异常则跳转到匹配的`catch`。
  2. 执行完`catch`后（若无异常则跳过`catch`），执行`finally`。
  3. 若`finally`中有`return`或抛出异常，会覆盖之前的返回值或异常。

#### Q5: ArrayList和LinkedList有什么区别？分别在什么场景下使用？

- **ArrayList** 基于动态数组，随机访问快（O(1)），插入/删除慢（需移动元素），适合频繁查询、较少增删的场景。
- **LinkedList** 基于双向链表，随机访问慢（O(n)），头尾插入/删除快，适合频繁增删、较少随机访问的场景（如队列、栈）。
