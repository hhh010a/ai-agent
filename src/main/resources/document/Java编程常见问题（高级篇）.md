- - # Java编程常见问题（高级篇）

    #### Q1: JVM内存模型是如何划分的？各区域的作用是什么？

    - JVM内存分为线程私有和线程共享区域：
      - **程序计数器**：线程私有，记录当前线程执行的字节码行号。
      - **虚拟机栈**：线程私有，存储栈帧（局部变量表、操作数栈、动态链接、方法出口）。
      - **本地方法栈**：为Native方法服务。
      - **堆**：线程共享，存放对象实例，垃圾回收的主要区域。
      - **方法区**（元空间）：线程共享，存储类信息、常量、静态变量、即时编译代码等。

    #### Q2: 垃圾回收算法有哪些？CMS和G1垃圾收集器的特点是什么？

    - 常用算法：**标记-清除**（产生碎片）、**标记-复制**（用于新生代）、**标记-整理**（用于老年代）。
    - **CMS**（Concurrent Mark Sweep）：以最短回收停顿时间为目标，并发收集，使用标记-清除算法，会产生碎片，且可能和用户线程并发时产生浮动垃圾。
    - **G1**（Garbage First）：面向服务端，将堆划分为多个Region，可预测停顿时间，整体采用标记-整理，避免碎片，支持并发收集，适合大堆内存。

    #### Q3: 谈谈你对AQS（AbstractQueuedSynchronizer）的理解，它在JUC中如何应用？

    - **AQS** 是Java并发包的基础框架，用于构建锁和同步器（如`ReentrantLock`、`CountDownLatch`、`Semaphore`）。
    - 核心是一个**volatile int state**（同步状态）和一个**CLH队列**（双向链表，存储等待线程）。
    - 子类需实现`tryAcquire`、`tryRelease`等方法控制状态，通过CAS修改state。
    - AQS提供了独占模式（如ReentrantLock）和共享模式（如Semaphore），支持可重入、中断、超时等特性。

    #### Q4: 如何实现一个自定义类加载器？有什么应用场景？

    - 继承`ClassLoader`，重写`findClass()`方法，在其中调用`defineClass()`将字节码转换为`Class`对象。
    - 若需打破双亲委派，可重写`loadClass()`。
    - 应用场景：
      - **热部署**：动态加载更新后的类。
      - **加密解密**：对字节码加密，自定义类加载器解密后加载。
      - **隔离应用**：如Tomcat为每个Web应用创建独立类加载器，避免冲突。

    #### Q5: 强引用、软引用、弱引用、虚引用的区别及使用场景是什么？

    - **强引用**（`new`）：普通对象引用，JVM宁愿OOM也不会回收。
    - **软引用**（`SoftReference`）：内存充足时不回收，不足时回收，适合做缓存（如图片缓存）。
    - **弱引用**（`WeakReference`）：下次GC时即被回收，适合实现**规范映射**（如`WeakHashMap`）。
    - **虚引用**（`PhantomReference`）：无法通过它获取对象，仅用于跟踪对象被回收的通知（与引用队列联合使用），如管理直接内存。
